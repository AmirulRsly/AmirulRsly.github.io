01 · About

I write the code and draw the art.

I'm a game developer at CraveFX in Kuala Lumpur, where I've built games and interactive installations since 2024: from a museum installation whose companion navigates using live MQTT coordinates, to optimising a game for WebGPU and mobile, to the front end of a multiplayer card game. Alongside that, I've been a freelance game developer since 2024, building web and mobile games for clients. Before CraveFX I made educational games at NovaLearn, and I hold a BCS (Hons.) in Multimedia Computing from UiTM (CGPA 3.64).

I'm also a 2D artist and animator. On my own games I program the systems, like turn-based combat, rhythm spawners and an enemy AI that uses fuzzy logic, and I draw and animate the characters frame by frame. That means I can talk to both the programmers and the artists on a team.
