03 · About

I program because I love making things.

I'm a Junior Interactive Media and Game Developer at CraveFX in Kuala Lumpur. Since 2024 my work has mainly been games, interactive experiences and web apps, built in Unity, Unreal Engine and PlayCanvas.

More about me

Highlights include an Unreal Engine museum installation whose companion navigates using live MQTT coordinates, optimising a game for WebGPU and mobile, and the front end of a multiplayer card game. I've also been freelancing since 2024, building web and mobile games for clients. Before CraveFX I made educational games at NovaLearn, and I hold a BCS (Hons.) in Multimedia Computing from UiTM (CGPA 3.64).

On my own games I focus on programming the systems, like turn-based combat, rhythm spawners and an enemy AI that uses fuzzy logic. Now and then I also draw and animate some of my own art, which helps me work smoothly with the artists on a team.
